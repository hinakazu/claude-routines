**ウクライナ和平交渉：米ウクライナが「空中停戦」案をロシアに提示へ**
ウクライナと米国は2026年7月26日時点で、地上戦を継続しながらも空域での攻撃停止を求める「空中停戦」案をロシアに提示することで調整を進めている。クレムリン報道官は「交渉プロセスに開放的」と述べつつも具体的コメントを避けた。7月8日にはアンカラのNATO首脳会議でトランプ大統領とゼレンスキー大統領が会談し、和平交渉の機運が高まっている。
📜 歴史的背景: ロシアは2022年2月24日にウクライナへの全面侵攻を開始し、4年以上が経過した今も戦闘は継続している。2026年4月（正教復活祭）・5月（ロシア戦勝記念日）に一時的停戦が合意されたが、ウクライナ側は7,696件の違反を記録しており、完全停戦の実現は依然困難な状況だ。

**USMCA見直し交渉：トランプ政権が協定延長を拒否、年次審査へ移行**
米国は2026年7月1日のUSMCA（米国・メキシコ・カナダ協定）16年延長オプションを行使せず、年次審査に移行した。カナダとメキシコはともに延長支持を表明したが、トランプ政権は自動車原産地規制の厳格化、対メキシコ貿易赤字の是正に加え、移民・麻薬問題での譲歩も要求している。5月に第1回米メキシコ二国間交渉が終了し、7月20日週にメキシコシティで第2ラウンドが実施された。
📜 歴史的背景: USMCAは2020年7月にNAFTA（北米自由貿易協定）の後継として発効し、北米3国間で年間約1.6兆ドルの貿易を規律する。2026年の見直しはこの協定内で唯一規定された「発効6年後の合同レビュー」であり、米国が延長拒否したことで毎年の再交渉という前例のない状況が生まれた。

**IMF世界経済見通し7月版：成長率3.0%維持もインフレ4.7%に再加速**
IMFは2026年7月8日発表の世界経済見通し更新版で、2026年の世界成長率を3.0%（2027年は3.4%）と4月時点から据え置いた。一方、世界のインフレ率は2025年の4.1%から2026年は4.7%へ上昇する見通しでディスインフレが停滞している。S&P500は7,428.78ポイントで推移し、AI過剰投資懸念と原油高が重しとなる一方、インドは6.4%成長で主要新興国トップを維持している。
📜 歴史的背景: 2022年のエネルギー危機・供給ショックで世界インフレが8〜10%台に達した後、各国中銀の急激な利上げにより2024年にかけて鎮静化が進んでいた。しかし戦争によるエネルギー価格上昇とAI投資ブームによる需要拡大が重なり、2026年は再び4%台のインフレが定着しつつある。

**OpenAI、GPT-5.6 Sol発表：Anthropic Fable 5を抜きコーディング首位奪還**
OpenAIは2026年7月9日にGPT-5.6ファミリー（Luna / Terra / Sol）を正式公開した。最上位モデル「Sol」はAI Analysis Coding Agent Indexで80点を記録しAnthropicのFable 5（77.2点）を上回り、Terminal-Bench 2.1では91.9%のスコアを達成。コンテキストウィンドウは105万トークン、API料金はFable 5比で約3分の1（$5/$30 per百万トークン）と高コスパを実現。同日にはxAIのGrok 4.5もリリースされ、史上最も激しいAIリリースデーとなった。
📜 歴史的背景: 2023年のGPT-4発表以降、Anthropic（Fable/Claude系）・Google（Gemini系）・Meta（Llama系）・オープンソース陣営（DeepSeek等）との性能競争が激化している。DeepSeekなどの無償オープンウェイトモデルがベンチマーク上位に迫る中、フロンティアAI企業のビジネスモデルの持続性が問われる転換点を迎えている。

**欧州・米国を直撃した記録的熱波：欧州6月だけで約2万人死亡**
2026年6〜7月にかけて欧州と米国を史上最大級の熱波が直撃した。西欧では2026年6月が観測史上最高気温の月となり、スロバキアで41.3℃、ハンガリーで42.0℃を記録。欧州だけで6月の超過死亡は約2万人に達し、フランスで2,000人超が確認された。米国でも約4,000万人が熱中症警戒下に置かれ少なくとも44人が死亡。ワシントンDCでは7月3〜4日に連日で最高気温記録が更新された（102°F・103°F）。
📜 歴史的背景: 2003年欧州熱波では7万人超が死亡し気候変動対策の転換点となった。2022年には61,000人超が熱波で死亡し、年々深刻化している。2026年のエルニーニョ強化が熱波をさらに増幅させており、アムネスティ・インターナショナルは化石燃料依存が「人権の危機」を招いていると警告している。
